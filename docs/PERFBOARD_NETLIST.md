## 3. STM32 기판 (NUCLEO-F401RE + HUB75)

출처: `rpi_c/stm32/Led_Matrix_Test/Led_Matrix_Test.ioc` GPIO_Label

### 3-1. HUB75 신호 매핑

Arduino 핀 이름이 D2~D15로 연속이라 배선이 단순하다.

| HUB75 | STM32 | Nucleo (Arduino) | 커넥터 |
|---|---|---|---|
| R1 | PA10 | D2 | CN9 |
| G1 | PB3 | D3 | CN9 |
| B1 | PB5 | D4 | CN9 |
| R2 | PB4 | D5 | CN9 |
| G2 | PB10 | D6 | CN9 |
| B2 | PA8 | D7 | CN9 |
| A | PA9 | D8 | CN5 |
| B | PC7 | D9 | CN5 |
| C | PB6 | D10 | CN5 |
| D | PA7 | D11 | CN5 |
| E | PA6 | D12 | CN5 |
| CLK | PA5 | D13 | CN5 |
| LAT | PB9 | D14 | CN5 |
| OE | PB8 | D15 | CN5 |

### 3-2. HUB75 2×8 커넥터 핀아웃 (표준 HUB75E)

```
     1 R1  │  2 G1
     3 B1  │  4 GND
     5 R2  │  6 G2
     7 B2  │  8 E
     9 A   │ 10 B
    11 C   │ 12 D
    13 CLK │ 14 LAT
    15 OE  │ 16 GND
```

> **확인 필요** — 코드가 `HUB75_SCAN_ROWS=16`(1/16 스캔)이라 행 선택에
> A~D 4비트면 충분하고 E는 불필요하다. 그런데 `.ioc`에는 E(PA6)가
> 정의돼 있다. 패널이 1/16이면 **8번핀이 E가 아니라 GND**인 제품이니
> 패널 실크를 보고 확정할 것.

### 3-3. UART (RPi C ↔ STM32) — 예약, 미구현

| STM32 | 기능 | Nucleo 커넥터 | RPi C |
|---|---|---|---|
| PC6 | USART6_TX | CN10 (Morpho) | Pi 물리 10 (GPIO15 RXD) |
| PA12 | USART6_RX | CN10 (Morpho) | Pi 물리 8 (GPIO14 TXD) |
| GND | — | CN10 | GND 공통 **필수** |

> PC6/PA12의 Morpho 핀 번호는 보드 실크로 확인할 것.
> TX↔RX가 교차 연결이라는 점 주의.

### 3-4. 전원

- **Nucleo는 USB로 급전**한다. 5V 라인에서 E5V로 넣으려면 JP5 점퍼를
  옮겨야 하고, 안 옮기면 안 켜지거나 USB와 충돌한다.
- **HUB75 패널 전원은 SMPS에서 직결**한다. 이 기판을 경유시키지 않는다
  (패널 피크 ~4A).
- 그래서 이 기판에는 전원 터미널이 없어도 된다.

### 3-5. 레벨 시프팅

Nucleo는 3.3V, HUB75는 5V 로직이 정격이다. **먼저 3.3V 직결로
테스트**하고, 화면이 깨지면 74HCT245를 넣는다.

- BSS138류 양방향 레벨 컨버터는 **쓰지 말 것.** I2C(400kHz)용이라
  상승시간이 μs대인데 HUB75 CLK는 MHz대라 파형이 뭉개진다.
- 나중에 넣을 수 있게 **DIP-20 자리 2개를 비워둘 것.**

## 4. 전원 분배

단자대 없이 SMPS 출력 단자에서 3갈래로 직접 딴다.

```
5V 10A SMPS ─┬─[16AWG]─→ HUB75 패널        (~4A)
             ├─[퓨즈 3A]─→ RPi C 기판       (~2A)
             └─[16AWG]─→ (STM32는 USB 급전이라 불필요)

RPi 4 본체 ── 별도 어댑터 (10A 공유 시 여유 1A뿐이라 언더볼티지 위험)
```

- SMPS 단자에 3가닥을 물릴 때는 **먼저 꼬아 납땜하고 수축튜브**로 감싼
  뒤 한 뭉치로 조인다. 대부분의 SMPS 단자는 2가닥이 정격이다.
- **GND는 반드시 SMPS 한 점에서 공통**으로 만난다. 안 그러면 서보 각도가
  튀고 UART가 안 붙는다.
- 퓨즈(S51 3A 지연형)는 RPi C 가지가 SMPS에서 갈라지는 지점 옆에 둔다.

## 5. RPi C 배치안 (존 분리)

I2C는 노이즈에 약하다. 스텝모터 배선이 SDA/SCL 옆을 지나면 PCA9685가
버스에서 간헐적으로 사라진다 — 재현이 안 돼 잡기 제일 어려운 증상이다.

```
┌──────────────────────────────────────────────────────┐
│ ┌──┐                              ┃  ┌─────────┐     │
│ │2 │  ┌──────────┐                ┃  │ ULN2003 │ ▣   │
│ │× │  │MAX98357A │                ┃  └─────────┘스텝 │
│ │20│  └──────────┘  ┌──────────┐  ┃                  │
│ │수│    ▣ 스피커     │ PCA9685  │  ┃  ┌──────┐  ▣    │
│ │헤│                └──────────┘  ┃  │HG7881│  펌프 │
│ │더│                    ▣ 서보     ┃  └──────┘       │
│ │  │  ▣ ▣ 리드센서                ┃ [MOSFET] ▣ 팬   │
│ └──┘                              ┃  [퓨즈] ▣ 5V IN  │
└──────────────────────────────────────────────────────┘
  ←──── 신호존 (3.3V) ────→          ┃ ←─ 전력존 (5V) ─→
                                     경계: GND만 한 점에서 연결
```

- PCA9685는 경계에 둔다. VCC(3.3V 로직)와 V+(5V 서보)를 동시에 받기
  때문에, 여기 두면 5V가 신호존을 가로지르지 않는다.
- 터미널(▣)은 전부 기판 가장자리. 밖으로 나가는 선이 기판 위를
  가로지르면 그때부터 배선이 엉킨다.
- 스텝모터 4선(Pi 29/31/36/37)은 한 다발로 붙여서 라우팅한다. 흩어지면
  그게 안테나가 된다.

## 6. 조립 순서

15가닥을 다 잇고 전원을 넣었는데 안 되면 후보가 15개다. 하나씩 하면
후보가 항상 방금 이은 것 하나다.

1. 전원레일 + GND + 퓨즈 → 5V/3.3V 전압만 먼저 측정
2. **PCA9685(서보)** → `i2cdetect`로 0x40 뜨는지 확인
3. 스텝모터 + 리밋
4. 펌프
5. 팬
6. MAX98357A

각 단계마다 `rpi_c/rpic_app/test/03_publish_cmds.sh`로 검증한다.
I2C를 제일 먼저 살려야, 이후 모터를 붙이면서 노이즈로 깨지는지 바로 안다.
