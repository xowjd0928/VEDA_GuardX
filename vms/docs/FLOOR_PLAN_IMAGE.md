# 평면도 배경 이미지 — 넣는 법·바꾸는 법

CROWD 히트맵과 LIVE ▸ FLOOR MAP 의 **바탕**을 도면 그림으로 깐다.
히트 셀·가시영역·동선·감지점은 예전과 똑같이 그 **위에** 그려진다 —
표시 방식은 하나도 바뀌지 않았다. 바탕만 바뀐다.

두 화면은 **같은 파일 하나**를 본다. 서로 다른 그림을 깔면 같은 현장을
두 모습으로 말하게 되기 때문이다.

---

## 1. 파일을 어디에 두나

```
C:\Users\<계정>\AppData\Local\GuardX\floorplan.png
```

자격 파일(`credentials.ini`)·인증서(`certs\`)와 **같은 폴더**다. 이미 아는
자리이고, 설치 경로나 작업 디렉터리에 의존하지 않는다.

다른 경로를 쓰고 싶으면 레지스트리에 절대 경로를 넣는다:

```
HKCU\Software\GuardX\VMS  →  floorplan_path = D:\plans\1F.png
```

파일이 없으면 예전 화면(1m 격자 + 방 외곽선 + 가구 상자)으로 그대로 돌아간다.
지우는 것이 곧 되돌리는 방법이다.

## 2. 그림을 어떻게 만드나 — **딱 하나만 지키면 된다**

> **그림의 네 모서리 = 방의 네 모서리.**

그림은 방 전체 `(0,0) ~ (room_w_cm, room_h_cm)` 에 맞춰 늘려 깔린다. 도면
바깥에 여백(흰 테두리·제목·범례)이 있으면 **그만큼 히트맵이 안쪽으로 밀려**
사람이 실제로 선 자리와 어긋난다. 벽 바깥은 잘라내고 저장할 것.

- 방 크기는 SETTINGS ▸ Floor calibration 의 캘리브레이션 값이다.
  LIVE ▸ FLOOR MAP 머리글에도 적혀 있다 (예: `1F · 170 × 120 cm`).
- **가로세로 비율을 방과 맞춘다.** 예: 170×120 cm → 1.417:1. 안 맞으면
  늘어나 보인다(잘리지는 않는다).
- 형식은 PNG·JPG 등 Qt 가 읽는 것 아무거나. 긴 변 1000~3000px 를 권한다 —
  화면에서 최대 1000px 정도로 그려지므로 그 이상은 메모리만 쓴다.
- **어두운 배경**을 권한다. 히트 색(초록→호박→빨강)과 동선 색이 밝은 쪽이라,
  흰 도면 위에서는 대비가 죽는다. 밝은 도면밖에 없으면 이미지 편집기에서
  반전하거나 어둡게 깔아서 저장하는 편이 낫다.

## 3. 바꾸는 법 — 파일만 덮어쓰면 된다

앱을 **끄지 않아도 된다.** 같은 이름으로 덮어쓰면 다음 그리기(≤250ms)에
바로 반영된다 — 수정 시각·크기가 바뀐 것을 보고 다시 읽는다.

```
1. 새 도면을 floorplan.png 로 저장 (위 §2 규칙대로 잘라서)
2. C:\Users\<계정>\AppData\Local\GuardX\ 에 덮어쓰기
3. CROWD 나 LIVE 화면을 보면 이미 바뀌어 있다
```

⚠ 파일이 잠겨 있거나(편집기에서 연 채 저장 중) 깨진 그림이면 조용히 옛
그림을 계속 쓴다. 안 바뀌면 파일을 먼저 확인할 것.

## 3b. 네모마다 다른 사진 붙이기 (가구 사진)

도면 위의 **각 가구 칸에 사진을 따로** 지정한다. 향수병 진열 사진처럼
탑뷰·정면 사진을 칸별로 넣고 싶을 때 쓴다.

```
C:\Users\<계정>\AppData\Local\GuardX\props\
```

### 어느 칸이 몇 번인가 — `_fixtures.txt` 를 열어 보면 된다

앱이 그 폴더에 대응표를 **자동으로** 적는다(캘리브레이션이 바뀌면 갱신):

```
 1.png  =  CH2 · LED Matrix    (30x15 cm, 가로)  [사진 없음]
 2.png  =  CH2 · 의자          (4x4 cm,   세로)  [사진 없음]
 3.png  =  CH2 · 가판대        (15x7 cm,  가로)  [사진 있음]
 ...
```

번호는 캘리브레이션 `obstacles` 의 순서다. 이름이 겹쳐도(가판대 6개, 의자
2개) 번호는 겹치지 않으므로 **칸 하나만** 골라 붙일 수 있다.

지도 위에서 눈으로 맞추고 싶으면 번호를 겹쳐 볼 수 있다:
`HKCU\Software\GuardX\VMS` → `floorplan_prop_keys = 1` (칸 좌상단에 호박색 번호).

### 파일 이름 규칙 — 먼저 있는 것이 이긴다

| 파일 이름 | 적용 범위 |
|---|---|
| `3.png` | **그 칸 하나** (권장) |
| `CH2-가판대.png` | CH2 안의 `가판대` 전부 |
| `가판대.png` | 이름이 `가판대` 인 칸 전부 |

확장자는 `png` · `jpg` · `jpeg` · `webp`. 사진은 칸 모양에 맞춰 **꽉 채워**
그려진다(비율 무시) — 세로 칸에는 정면 사진, 가로 칸에는 탑뷰 사진이 자연스럽다.

### 바꾸는 법

파일을 덮어쓰면 **앱을 끄지 않아도** 다음 그리기에 바뀐다(도면 이미지와 같은
규칙). 지우면 그 칸은 사진 없는 상태로 돌아간다.

⚠ 사진을 지정한 칸은 **도면 위에도 항상 그려진다**. 도면에 이미 그 가구가
그려져 있다면 두 겹이 되므로, 도면 쪽에서 그 자리를 비워 두거나 사진을 빼는
편이 낫다.

## 4. 선택 설정

| 레지스트리 값 (`HKCU\Software\GuardX\VMS`) | 기본 | 뜻 |
|---|---|---|
| `floorplan_path` | (비움) | 도면 경로 재지정. 비우면 §1 기본 자리 |
| `floorplan_show_obstacles` | `0` | 도면 위에 캘리브레이션 가구(발자국)도 그릴까 |

`floorplan_show_obstacles=1` 은 **캘리브레이션 좌표를 눈으로 검증할 때**만
쓴다 — 도면에 이미 가구가 그려져 있으면 두 겹이 되어 서로 싸운다. 기본이
꺼짐인 이유다. (도면 파일이 없을 때는 이 값과 무관하게 예전처럼 가구를
그린다. 그때는 가구가 유일한 지형지물이다.)

## 5. 지금 들어 있는 것

설치 직후에는 파일이 없다. 개발 PC 에는 **자리표시용 도면**(어두운 바탕에
방 외곽선만)이 들어 있다 — 진짜 도면으로 덮어쓰면 된다.

격자를 원하면 도면 그림에 직접 그려 넣는다. 앱이 그리는 1m 격자는 **도면
파일이 없을 때만** 나온다 (있으면 선이 두 겹이 되므로 그리지 않는다).
